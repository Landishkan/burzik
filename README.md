# Pixel

Тренажёр критического мышления для подростков 14–17 лет: уроки, мини-игры и расследование «Северного ветра».
Сайт: https://pixel-edu.ru/

Приложение статическое: открывается как обычный сайт, без сборки и без сервера. Данные учеников хранятся только на их устройстве.

## Что где лежит

| Путь | Что это |
|---|---|
| `site/index.html` | всё приложение: дорожка, улица, игры, темы, напарники |
| `site/content.js` | **уроки и задания: здесь правятся тексты** (подробная инструкция в начале файла и в `CONTENT.md`) |
| `site/sw.js` | офлайн-режим |
| `site/manifest.webmanifest`, `site/icons/` | установка на главный экран |
| `site/fonts/` | шрифты (лежат внутри приложения, внешних запросов нет) |
| `site/CNAME` | адрес сайта |
| `site/agentstvo/` | старый адрес, перенаправляет на главную |
| `legacy-react/` | прежняя версия на React, не используется и не публикуется, оставлена на память |

## Как опубликовать правки
Всё, что попадает в ветку `main`, само выкладывается на сайт (раздел Actions, 1–2 минуты).
Перед выкладкой автоматически проверяется, что `site/content.js` читается. Если в нём ошибка, выкладка остановится, а сайт останется прежним.

## Как посмотреть у себя на компьютере
```bash
python3 -m http.server 8000 --directory site
```
Потом открыть http://localhost:8000/ . Если в `content.js` есть ошибки, сверху появится красная плашка со списком.
